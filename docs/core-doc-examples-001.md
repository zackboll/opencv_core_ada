## Reproduction and delivery boundary

From the repository root:

```sh
sh scripts/install_doc_enhancer.sh
sh scripts/generate_docs.sh
.doc-tools/enhancer/bin/python -m unittest discover -s scripts -p 'test_*.py' -v
sh scripts/acquire_core_doc_baseline.sh
.doc-tools/enhancer/bin/python scripts/compare_core_doc_examples.py
.doc-tools/enhancer/bin/python scripts/gnatdoc_browser_oracle.py
```

The documentation workflow runs all new gates. Historical artifact acquisition
requires an authenticated token with actions-read access and fails closed if
the evidence expires. PR jobs never upload or deploy Pages; the existing main-only
guards and 30-day Pages retention remain intact. No merge, tag, release,
auto-merge or deployment is authorized. Exact final commit/tree, pushed/PR head
identity, changed-file inventory and hosted results are recorded on the single
non-draft PR rather than embedding a circular claim about this file's own commit.
