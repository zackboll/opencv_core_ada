# CORE-DOC-EXAMPLES-001 local qualification evidence

See [the handoff](../core-doc-examples-001.md) for pinned release/source identities,
trust boundaries, exact totals, reproduction and limitations. These are local
captures, not a claim that hosted CI has already passed. The PR records exact
commit/tree and hosted results independently.

* `python-tests.log`: all 178 Core documentation tests, zero failures/skips.
* `example-mutations.log`: focused 22-test rerun after pinning the 210-file policy.
* `fresh-generation-{one,two}.log`, `determinism.log`, `idempotent.log`,
  `released-verification.log`: two additional fresh native/site generations,
  byte-identical recursive comparisons, reapplication, released verification
  and final independent reconstruction/historical comparison.
* `historical-{run,artifact}.json`: authenticated GitHub metadata for the
  successful exact-main 209-file input. Archive SHA-256 is pinned in the handoff,
  acquisition script and comparison record; all members match the immutable
  historical inventory. No cached bytes substitute for authenticated acquisition.
* `publication-comparison.json`: seven authorized changes, one new CSS asset,
  202 byte-identical resources, no removals; exact before/after SHA-256 values.
* `source-native-examples-oracle.json`: reconstructed original text, token counts
  and exact API destinations for every block; generated by Core's independent
  policy against pristine source/native inputs, not the enhancer's metadata.
* `examples-browser.{log,json}`: eight Chromium configurations; 312 native
  clipboard copies, 184 keyboard API arrivals; zero external requests/errors.
* `landing-browser.log`, `landing-visual.json`: eight tightly scoped pixel
  comparisons to original HTML and authenticated v0.1.3, original geometry,
  exact CSS inventory, focus/contrast and unauthorized-CSS/missing-rule rejection.
* Other `*-browser.log` files: all retained search/navigation/history, symbols,
  cross-origin, exhaustive migration and five-guide suites.
* `installed-consumer.log`, `external-shim.log`: fresh installed/relocated
  consumers and three installation tests, with the supported Alire environment.
* `screenshots/`: representative desktop light/mobile dark homepage before/after,
  raw pixel differences, unauthorized-CSS mutation, and unchanged-source guides.
  The complete capture matrix is generated in `obj/docs/browser-screenshots`
  and uploaded by hosted CI.

Exploratory failures are not represented as successful gates: the old Core oracle
correctly rejected new markup before adaptation; a first run overlapped the
type-context correction; a later test exposed the now-split literal mutation
target, which was corrected without weakening rejection. An initial direct
external-shim invocation lacked `gprinstall` on PATH and was rerun successfully
under the required `alr exec` environment. Stable qualification suites and fresh
generation were serialized to avoid copying transient publication files.

The approved sources have no character-literal token. Six other supported
classes occur and have exact computed-color checks; absence of the seventh is
explicitly recorded without editing authored inputs to manufacture coverage.
No merge, auto-merge, tag/release or Pages deployment is performed.
