OpenCV Core Ada

A thick, idiomatic Ada 2022 binding for the OpenCV Core module, with controlled resources, strong types, typed access and Ada exceptions.

Generated Ada API reference

The package specifications are the authoritative API declarations. The repository README defines the supported OpenCV version policy (currently 4.1 through 5.0, inclusive; not every intermediate release is explicitly tested).

Install with Alire

alr with opencv_core

Install the native OpenCV development library and pkg-config as described in the README. This crate covers Core only, not image codecs or GUI modules.

Basic usage

with OpenCV.Core;

procedure Example is
   use OpenCV.Core;
   Image : constant Mat := Create (2, 3, (Depth => UInt8, Channels => 1));
   Copy  : constant Mat := Image.Clone;
begin
   pragma Assert (Copy.Rows = 2 and then Copy.Columns = 3);
end Example;

Assignment shares OpenCV storage; Clone makes a deep copy.
